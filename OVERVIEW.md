User Todos gives the tasks an agent hands you, the ones only you can do, a place to wait: a Todos panel in the Explorer, beside the chat.

An agent that needs you to make an account, paste a key into a dashboard, approve a change at a registrar or test on a real phone proposes a todo instead of burying the ask in a reply. Each todo has a short reason, a bulleted list of steps, the exact links you need, labels, and a jump back to the message it came from.

How it works:

- A proposal is held back for a turn or two (1 to 3, your choice) and shows only if you haven't answered it in chat. If you resolve it first, the agent withdraws it.
- Every card has a colored status pill at its top right: TODO, DOING, HOLD, DONE and CANCEL to start with. A click opens the status list; swiping a card right past about 90px marks it DONE, and swiping left archives it. A status other than TODO tints the card faintly in its color. Edit the list from the gear (names, colors, icons, order, and whether a status closes a todo). Moving a card between an open status and a closing one (DONE, CANCEL) tells the agent in the chat. Moving between open statuses tells no one. Archiving a todo tells the agent too. A chat archived in Paseo is never messaged.
- Cards drag to reorder. The sort menu groups by chat or by status and sorts newest first, oldest first or manually; dragging switches to manual and remembers the order per chat.
- Labels are Paseo's workspace labels plus any you make here, in Paseo's colors. The "#" button in the card's last row, beside the time, opens a menu of them; a tap adds or removes one on the todo, and it never touches a workspace. "Create label" adds a label to Paseo's own list. Paseo makes it violet, so the color you pick shows in the panel until you recolor it in Paseo. Agents do not set labels.
- A speech-bubble button in the card's last row, left of "#", shows how many comments the todo has and opens a comment field under the steps. Enter adds a comment, Shift+Enter starts a new line, and the small cross on a comment removes it. When you close a todo, the message to the agent carries every comment you left. Reopening it passes on the comments added since it closed. The agent can also read them with the list tool.
- "+" opens a blank card at the top of the list for a todo of your own. It shows at once, and closing it tells no one.
- The Current / All switch sits in the panel header. "All" lists every chat's todos in the workspace, grouped by chat or by status, and each group folds.

Setup: the plugin adds three tools (propose, withdraw and list) and a short standing instruction to every agent you can see, so agents know to hand you a todo instead of asking in prose. Codex chats pick up the instruction with their next prompt; Claude Code chats started before the plugin keep the instruction they began with, so they get the tools but not the nudge. Settings, in the panel's gear: how many turns to wait, whether the panel opens by itself, confetti, and the status list.

Limits: Paseo has no plugin call to list or edit its workspace labels, so they are read from its labels file on the daemon host and never written; a label made here is created by briefly assigning it to the current workspace. Todos are stored on the daemon's machine, so they follow the host, not the client. Jumping to a message scrolls the chat only on the web and desktop app; elsewhere it opens the chat. Dragging a card works with a mouse or, on touch, after a long press.
